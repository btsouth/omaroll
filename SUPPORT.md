# Support

Please include diagnostics with a bug report. In Omaroll 1.19 or newer, open
Settings and choose **Copy diagnostics** under About, or run this if no window
opens:

```bash
omaroll --diagnostics
```

Both give the Omaroll, Qt, Omarchy and Hyprland versions, the graphics card
and driver, the theme and which optional tools are installed. Copy diagnostics
also gives the display scale; with the command, say your scale yourself. They
leave out file names and paths. On an older version, run `omaroll --version`
and name your Omarchy version and graphics card instead.

Also include:

- Image or video format
- Whether the file is local, removable, or on a network mount
- The shortest steps that reproduce the problem

Remove private filenames and paths from screenshots or logs before posting.
