Built for Omarchy

Your photos,
as good-looking as your desktop.

Double-click a picture or video and it opens in a viewer that follows your Omarchy theme, with the rest of the folder an arrow key away. Press Enter for the library, where your PDFs, screenshots and recordings are too.

Free and open source, for x86_64 and ARM64 on Omarchy and Arch Linux.

Install Omaroll See every feature

Install from the signed repository

One command adds the repository and installs Omaroll:

curl -fsSL https://pkgs.btso.dev/install.sh | bash -s -- omaroll

Updates then arrive with your normal system update (omarchy update on Omarchy, sudo pacman -Syu on plain Arch). On Omarchy's edge channel, Omaroll is also in the official repository: sudo pacman -S omaroll. Set Omaroll as the default for pictures and videos, or run omaroll photo.jpg from a terminal.
