# Changelog

## 1.0.0

- Added a fast image and video viewer with folder navigation, zoom, pan,
  rotation, video scrubbing, fullscreen, and slideshows.
- Added a local library for pictures, videos, downloads, and custom folders.
- Added named albums that repair entries after safe file moves or renames.
- Added search, filters, sorting, favourites, hidden items, multi-selection,
  drag and drop, clipboard actions, and XDG Trash.
- Added theme-aware presentation mattes and integrations with Omarchy media tools.
- Added broad image and video format support, bounded thumbnail caching, and
  live library updates.
